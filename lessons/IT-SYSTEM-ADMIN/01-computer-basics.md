## 1. What is a computer?

A computer does three basic things:

**INPUT → PROCESSING → OUTPUT**

Example:

- You press a key = INPUT
- CPU works on it = PROCESSING
- A letter appears on screen = OUTPUT

## 2. Hardware

**Hardware = the physical stuff you can touch.**

Examples:

- CPU
- RAM
- SSD
- keyboard
- mouse
- monitor
- network card

Think of hardware as the computer's body.

## 3. CPU

CPU = **Central Processing Unit**.

Think of it as the worker/chef who follows instructions.

It executes instructions and performs calculations.

## 4. RAM

RAM is temporary working memory.

Think:

> RAM = the worker's desk.

The worker puts things on the desk while working. When power is removed, normal RAM contents do not remain like permanent storage.

## 5. SSD

SSD is permanent storage.

Think:

> SSD = the warehouse.

Windows, applications, documents, photos and other files live there.

## 6. Windows

Windows is an **operating system**.

Think of Windows as the manager between applications, users and hardware.

It manages things such as:

- CPU time
- memory
- files
- processes
- devices
- users
- permissions
- networking
- services

## 7. File

A file is stored information.

Examples:

- `photo.jpg`
- `notes.txt`
- `program.exe`
- `report.pdf`

## 8. Folder

A folder is a container used to organize files and other folders.

Example:

```text
Documents
├── report.pdf
├── notes.txt
└── Projects
    └── app.exe
```

## 9. Drive

Windows commonly uses drive letters such as:

- `C:`
- `D:`
- `E:`

A path can look like:

```text
C:\\Users\\YourName\\Documents
```

## 10. User and Administrator

A **user account** identifies who is using Windows.

An **administrator** has elevated permissions that allow management of parts of the system that ordinary users may not be allowed to change.

Administrator does **not** mean unlimited magical power. Windows still has security boundaries.

## 11. Bits and bytes

A **bit** is a tiny binary value: `0` or `1`.

A **byte** contains 8 bits.

```text
1 byte = 8 bits
```

## Tiny real Windows lab

1. Press `Ctrl + Shift + Esc` to open Task Manager.
2. Look at CPU, Memory, Disk and Network.
3. Press `Win + E` to open File Explorer.
4. Open **This PC** and observe the available drives.
5. Look at `C:\\Users`.

**Do not delete anything during this beginner lab.**

Scripting Academy Privacy Policy

Last updated: 6 October 2026

App: Scripting Academy

Information we collect

Scripting Academy does not require an account. The core app does not intentionally collect names, email addresses, contacts, precise location, microphone data, camera data, SMS data, phone data, or advertising identifiers.

Information stored on your device

Lessons, notes, progress, preferences, projects and workspace information may be stored locally on your Android device. Core learning data is not automatically uploaded to a Scripting Academy server.

Optional Windows Lab

The app can optionally connect to a Windows Lab Agent selected and configured by the user. When this feature is used, source code, test input and terminal requests are sent over the network to that Windows computer so its installed tools can execute them. Compiler output, program output, errors, exit codes and related execution results may be returned to the app.

Network and security

The Android app requires network access for optional Windows Lab connectivity. Users should connect the lab feature only to a trusted computer and network. The Windows Lab Agent should not be exposed directly to the public internet.

Data sharing

The core app does not sell user data and does not require an advertising or analytics SDK. Optional Windows Lab data is sent to the Windows endpoint configured by the user.

Retention and deletion

Local learning data remains on the device until the user clears the app data, uses available in-app deletion controls, or uninstalls the app. Optional Windows Lab data is handled by the user's Windows computer and its local configuration.

Children

Scripting Academy is an educational programming application. It does not intentionally collect personal information from children.

Privacy contact

Privacy questions can be submitted through the developer contact information shown on the Scripting Academy Google Play listing.

Changes

This policy may be updated when the app's data practices change. The latest version will be published on this page.

Scripting Academy Privacy Policy

Last updated: 5 October 2026

App: Scripting Academy

Information we collect

Scripting Academy does not require an account and the core app does not intentionally collect names, email addresses, contacts, precise location, microphone, camera, SMS, phone data, or advertising identifiers.

Information stored on your device

Lessons, notes, progress, preferences, and local project/workspace data may be stored on your Android device using local app storage. This information is not automatically uploaded to our servers by the core app.

Optional Windows Lab

The app can optionally connect to a Windows Lab Agent selected and configured by the user. When you use this feature, source code, test input, and terminal requests are sent over the network to that Windows computer so its installed toolchains can execute them. The response, such as program output or compiler errors, is returned to the app. The Windows Lab is intended for a computer controlled by the user and should not be exposed to the public internet.

Network and security

The Android app requires network access for optional Windows Lab connectivity. The core app does not include an advertising or analytics SDK. Users should only connect the lab feature to a trusted computer and network.

Data sharing

The core app does not sell user data. Optional Windows Lab data is sent only to the Windows endpoint that the user configures. No third-party advertising network is required by the app.

Retention and deletion

Local learning data remains on the device until the user clears the app's data, removes the data through the app's available controls, or uninstalls the app. Optional Windows Lab data is handled by the user's Windows computer and its local configuration.

Children

Scripting Academy is an educational programming application. It does not intentionally collect personal information from children.

Privacy contact

Privacy questions can be submitted through the developer contact information shown on the Scripting Academy Google Play listing.

Changes

This policy may be updated when the app's data practices change. The latest version will be published on this page.

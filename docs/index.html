Scripting Academy Privacy Policy

Last updated: 5 October 2026

Scripting Academy does not require an account and does not intentionally collect personal information.

Local data

Lessons, notes, progress and workspace data may be stored locally on the device.

Windows Lab

If the user connects to their own Windows Lab Agent, source code and terminal requests are sent to the Windows computer selected by the user. This is optional. The Windows Lab Agent is intended for a computer controlled by the user and should not be exposed to the public internet.

Permissions and network

The app uses network access only when needed for optional Windows Lab connectivity and related web content. The app does not require contacts, location, microphone, camera, SMS, phone, or storage permissions.

Third parties

The core app does not require advertising or analytics SDKs.

Contact

For privacy questions, please use the contact information provided on the app's Google Play listing.
